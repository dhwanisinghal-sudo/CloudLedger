# CloudLedger: your cloud bill as a cost sheet

## Run it
Download `CloudLedger.html` and open it in any browser. No internet or install needed.
Pick an example from the dropdown, or edit any box; every table updates.

## What it does
1. **Classify** each charge as direct (allocated) or indirect (shared). (M3)
2. **Apportion** shared costs on a driver, re-apportion service centres, absorb overheads. (M3)
3. **Unit economics**: cost per user, BEP price, BEP sales, margin of safety, target profit, budget variance alert. (M4, M5)

## Verified against class problems
- Stitching / Finishing / Canteen (Module 3): 45,000 and 15,000; rates 150 and 100
- Dept A / B / X exercise (Module 3): 13,680 and 9,320; rates 13.68 and 18.64
- Steel water bottles (Module 4): BEP 1,500 units, margin of safety 100, target profit 1,800 units
